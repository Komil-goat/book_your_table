
# Café Website

This is a frontend-only web application built with React and Vite. The website allows users to view table layouts, check availability, and reserve tables at a cafe.

### Features

- View table layout with availability.
- Reserve a table via interactive UI.
- View a list of current bookings.
- Display prices for different types of tables.
- Confirmation popups for actions.

## Installation and Run Guide

**Note:** Node.js must be installed. You can download it from https://nodejs.org/

1. Clone the repository:

```bash
git clone https://github.com/NUU-SE201/bug-writers.git
```

2. Navigate to the project folder:

```bash
cd bug-writers
```

3. Install dependencies:

```bash
npm install
```

4. Run the project locally:

```bash
npm run dev
```

5. Open your browser and go to the URL shown in the terminal (usually http://localhost:5173).
